# 🐺 MistraelSL Extension Manager for SillyTavern

Стеклянный интерфейс для штатного окна управления расширениями SillyTavern. Расширение не заменяет внутреннюю систему управления: оно аккуратно перестраивает существующее окно, сохраняя совместимость со штатными кнопками обновления, включения, отключения, смены ветки и удаления.

## Что уже есть в версии 0.2.0

- стеклянное адаптивное окно в цветах активной темы SillyTavern;
- сворачиваемые разделы **«Комплектные расширения»** и **«Установленные расширения»**;
- запоминание состояния каждого раздела;
- поиск по отображаемому и техническому названию;
- фильтры «Все», «Включённые», «Выключенные» и «Обновления»;
- счётчики установленных, активных и ожидающих обновления расширений;
- отдельный режим массового выбора сторонних расширений с круглыми маркерами;
- визуально отличимые тумблеры штатного включения и выключения расширений;
- массовое включение и выключение через штатные переключатели SillyTavern;
- массовое удаление с единым подтверждением и отчётом об ошибках;
- экспорт установленных сторонних расширений в переносимый JSON-профиль;
- предварительный просмотр и массовое восстановление расширений из профиля;
- восстановление включённого и выключенного состояния через штатные функции SillyTavern;
- защита менеджера от случайного самоудаления;
- мобильная раскладка, клавиатурный фокус и режим уменьшенной анимации;
- русская и английская локализация интерфейса менеджера.

Комплектные расширения по умолчанию свёрнуты, а установленные — открыты. Выбранное состояние сохраняется в браузере.

## Резервная копия расширений

Кнопка **«Экспорт»** создаёт файл вида `MistraelSL-Extensions-Backup-YYYY-MM-DD.json`. В профиль входят только техническое имя расширения, его отображаемое имя, безопасная HTTPS-ссылка на Git-репозиторий, ветка, commit, версия манифеста и включённое состояние.

Локальные пути, пользовательские настройки расширений, чаты, API-ключи, пароли и токены в профиль не записываются. Если Git-адрес содержит встроенные учётные данные или параметры запроса, они удаляются перед экспортом.

Кнопка **«Импорт»** сначала показывает стеклянное окно предварительного просмотра. Уже установленные расширения, текущий менеджер и записи без доступного репозитория помечаются отдельно. Выбранные расширения устанавливаются по очереди через штатную функцию SillyTavern, после чего восстанавливается их включённое или выключенное состояние.

Комплектные расширения SillyTavern в резервную копию не включаются: они устанавливаются и обновляются вместе с самой программой.

## Установка после публикации на GitHub

1. Опубликуйте эту папку как отдельный репозиторий GitHub.
2. Скопируйте HTTPS-ссылку репозитория, например `https://github.com/USERNAME/REPOSITORY`.
3. В SillyTavern откройте панель **«Расширения»**.
4. Нажмите **«Установить расширение»**.
5. Вставьте ссылку на репозиторий и подтвердите установку.
6. Перезагрузите страницу SillyTavern.
7. Нажмите **«Управление расширениями»** — откроется новый интерфейс.

## Важное замечание о массовом удалении

Обычное удаление одного расширения штатной кнопкой SillyTavern остаётся без изменений и может предложить индивидуальную очистку данных, если расширение её поддерживает.

Массовое удаление использует тот же серверный маршрут удаления SillyTavern, но не запускает индивидуальные клиентские `clean`/`delete`-хуки каждого расширения. Поэтому файлы расширений удаляются, но часть сохранённых настроек может остаться. Это явно указано в окне подтверждения. Если требуется полная очистка данных конкретного расширения, безопаснее удалить его отдельно штатной кнопкой.

## Как это работает

После появления штатного элемента `.extensions_info` менеджер:

1. находит созданные SillyTavern карточки расширений;
2. сохраняет их существующие обработчики и кнопки;
3. помещает штатные контейнеры в новую адаптивную оболочку;
4. добавляет собственные поиск, фильтры, сворачивание и массовый выбор;
5. отслеживает появление индикаторов обновлений и обновляет счётчики.

Такой подход менее хрупок, чем копирование всей внутренней функции SillyTavern: штатные операции продолжают выполняться кодом текущей версии приложения.

## Файлы проекта

- `manifest.json` — манифест расширения;
- `index.js` — интеграция, фильтры, сворачивание и пакетные операции;
- `style.css` — стеклянная тема и адаптивная раскладка;
- `LICENSE` — лицензия MIT.

## Совместимость

Первая версия подготовлена по структуре актуальной локальной установки SillyTavern на момент разработки, где кнопка менеджера имеет идентификатор `#extensions_details`, а окно использует `.extensions_info` и `.extension_block`.

Если после обновления SillyTavern штатная разметка изменится, расширение не удаляет и не перезаписывает её. Оно выведет предупреждение в консоль и оставит нативное окно работоспособным.

## Разработка

После изменения файлов перезагрузите страницу SillyTavern с очисткой кэша (`Ctrl+F5`). Для диагностики откройте инструменты разработчика браузера (`F12`) и найдите сообщения с префиксом `[MistraelSL Extension Manager]`.
